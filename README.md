# Titanic Dataset - Exploratory Data Analysis (EDA)

This project performs exploratory data analysis (EDA) on the Titanic dataset.

## Files Included

- `train.csv`: Contains the training data used for EDA, including passenger info and survival status.
- `test.csv`: Contains similar features but without survival status (used for predictions).
- `gender_submission.csv`: Example of a submission file format for classification results.

## EDA Overview

The analysis includes:

- Data structure and missing values overview
- Distribution of survival across gender and class
- Age distribution visualization
- Correlation heatmap of numerical features

## Key Insights

- Females had a much higher survival rate than males.
- 1st class passengers had the highest survival rate.
- Age, gender, and class showed significant impact on survival.

## Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib
